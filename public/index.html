智启 Markdown 转 Word

把已确认的 Markdown 教案转成原生 Word 文档，供智启插件调用。本页只提供说明，不会在浏览器里保存或填写 API 密钥。

支持的 Markdown

  • H1 至 H6、段落、粗体、斜体、删除线、行内代码、超链接
  • 有序/无序列表（最多三级嵌套）、引用、分隔线、围栏代码块
  • Markdown 表格转为 Word 原生表格
  • HTTPS 公网 PNG/JPEG/GIF/BMP 图片嵌入；SVG 第一版不支持

API 请求示例

POST /api/generate-docx
Content-Type: application/json
x-api-key: 仅在智启插件配置中填写，不要写进网页

{
  "markdown": "# 小学三年级数学跨学科教案\n\n完整教案内容……",
  "filename": "小学三年级数学-乘除法的应用（二）-科学跨学科教案",
  "document_title": "乘除法的应用（二）——溶解速度公平实验"
}

返回示例

{
  "code": 200,
  "word_status": "success",
  "word_url": "https://……/xxx.docx",
  "word_filename": "小学三年级数学-乘除法的应用（二）-科学跨学科教案.docx",
  "word_size_bytes": 123456,
  "word_message": "",
  "warnings_text": "",
  "expires_at": ""
}

失败时 word_status 为 error，word_url 必须是空字符串。

安全说明

  • 转换接口需要 x-api-key。密钥只配置在 Vercel 与智启插件中。
  • 生成的 DOCX 存在 public Blob，拿到链接的人都可以下载，不要用于含敏感学生信息的文档。
  • 只下载 HTTPS 图片，并拒绝内网、localhost 与云元数据地址。
  • 不执行 Markdown 中的 HTML、JavaScript 或 CSS。
